# IETF (Internet Engineering Task Force)

An open standards organization that develops and promotes voluntary Internet standards, particularly the TCP/IP protocol suite.

## Key Outputs
- **RFC (Request for Comments)** - Technical specifications
- **BCP (Best Current Practice)** - Implementation guidelines
- **STD (Standard)** - Official Internet Standards

## Important RFCs
| RFC      | Protocol/Standard |
| -------- | ----------------- |
| RFC 791  | IPv4              |
| RFC 793  | TCP               |
| RFC 768  | UDP               |
| RFC 2460 | IPv6              |
