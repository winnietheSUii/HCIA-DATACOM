# CLI (Command Line Interface)

A text-based interface for interacting with network devices through commands.

## Huawei VRP CLI Views

| View | Prompt | Purpose |
|------|--------|---------|
| User View | `<Huawei>` | Basic monitoring |
| System View | `[Huawei]` | Global configuration |
| Interface View | `[Huawei-GigabitEthernet0/0/1]` | Interface config |
| Protocol View | `[Huawei-ospf-1]` | Protocol config |

## Common Navigation Commands
```
system-view          # Enter system view
quit                 # Go back one level
return               # Return to user view
```

## Command Shortcuts
- `?` - Help
- `Tab` - Auto-complete
- `↑/↓` - Command history
