# Collision Domain

A network segment where two devices transmitting simultaneously can cause a collision. Relevant to half-duplex shared media.

## Characteristics
- Collisions occur on shared media (hubs, coax bus) using [[CSMA-CD]]
- Only one device can transmit at a time per collision domain
- [[Ethernet Switch]] ports create separate collision domains
- Full-duplex links eliminate collisions entirely

## How to Reduce Collisions
- Replace hubs with switches
- Use full-duplex links
- Segment networks with switches/routers
