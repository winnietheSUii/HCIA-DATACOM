# 802.1Q

IEEE standard for [[VLAN]] tagging on Ethernet frames. Inserts a 4-byte tag to identify VLAN membership.

## Tag Format

Inserted between source MAC and EtherType/Length:

```
| TPID (2 bytes) | TCI (2 bytes) |
  0x8100           PCP|DEI|VID
```

- **TPID** (Tag Protocol Identifier): 0x8100 (indicates 802.1Q tag)
- **TCI** (Tag Control Information):
  - **PCP** (Priority Code Point, 3 bits): [[QoS]] priority (0-7)
  - **DEI** (Drop Eligible Indicator, 1 bit): Can frame be dropped under congestion?
  - **VID** (VLAN Identifier, 12 bits): VLAN ID (0-4095; 0 and 4095 reserved)

## Frame Size Impact

- Adds 4 bytes → standard max frame becomes 1522 bytes (instead of 1518)
- Can cause MTU issues if not accounted for

## Native VLAN

- Untagged traffic on [[Trunk Port]]
- Default VLAN 1 (configurable)
- Security risk if mismatched between switches

## Tagging Behavior

- **[[Access Port]]**: Switch adds tag on ingress, removes on egress
- **[[Trunk Port]]**: Frames remain tagged (except native VLAN)
- **[[Hybrid Port]]**: Configurable per-VLAN

## Double Tagging (Q-in-Q)

- **802.1ad** (Provider Bridging): Outer tag for service provider, inner for customer
- Used in metro Ethernet, MPLS L2VPN
