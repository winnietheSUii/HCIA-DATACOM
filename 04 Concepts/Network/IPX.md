# IPX (Internetwork Packet Exchange)

A legacy network [[Protocol]] developed by Novell for use in NetWare networks, now largely obsolete.

## Key Points
- Proprietary protocol primarily used by NetWare operating systems
- Operated at Layer 3 (Network Layer)
- Has been replaced by [[IPv4]] as the dominant network protocol
- Rarely used in modern networks

## Historical Note
IPX was important in the 1980s-1990s for local area networks but became obsolete with the dominance of TCP/IP.
