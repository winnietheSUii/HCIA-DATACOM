# IEEE (Institute of Electrical and Electronics Engineers)

A professional organization that develops standards for electrical, electronic, and networking technologies.

## Key IEEE 802 Standards

| Standard | Technology | Description |
|----------|------------|-------------|
| 802.1D | STP | Spanning Tree Protocol |
| 802.1Q | VLAN | VLAN tagging |
| 802.1X | Port Security | Port-based authentication |
| 802.3 | Ethernet | Wired LAN |
| 802.11 | Wi-Fi | Wireless LAN |
| 802.11a/b/g/n/ac/ax | Wi-Fi variants | Different speeds/frequencies |

## IEEE 802.3 Ethernet Standards
| Standard | Speed | Media |
|----------|-------|-------|
| 10BASE-T | 10 Mbps | Twisted pair |
| 100BASE-TX | 100 Mbps | Cat5 UTP |
| 1000BASE-T | 1 Gbps | Cat5e/6 UTP |
| 10GBASE-T | 10 Gbps | Cat6a/7 |
