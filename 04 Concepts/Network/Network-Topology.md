# Network Topology

The physical or logical arrangement of nodes and connections in a network.

## Physical Topology Types

### Star Topology
- All nodes connect to central switch/hub
- Easy to manage, single point of failure
- Most common in modern LANs

### Bus Topology
- All nodes share a single backbone
- Legacy design (10BASE2, 10BASE5)
- Collision domain issues

### Ring Topology
- Nodes connected in circular fashion
- Token passing mechanism
- Used in legacy Token Ring, FDDI

### Mesh Topology
- Multiple paths between nodes
- High redundancy
- Used in WAN, data centers

### Tree (Hierarchical) Topology
- Combination of star topologies
- Common in enterprise networks
