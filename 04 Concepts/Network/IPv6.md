# IPv6

The next-generation version of the Internet Protocol with 128-bit addresses, designed to overcome IPv4 limitations.

## Key Improvements
- **Larger address space** - 128-bit addresses (2^128 possibilities) vs IPv4's 32-bit
- **Simplified header** - Cleaner, more efficient processing
- **Built-in security** - IPsec integrated by default
- **Better support for real-time traffic**
- **Automatic configuration** - Simplified network setup

## Contrast with IPv4
[[IPv4]] uses 32-bit addresses; IPv6 uses 128-bit addresses for vastly more available IPs.
