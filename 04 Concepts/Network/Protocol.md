# Protocol

A set of rules and standards that define how data is formatted, transmitted, and received between devices in a network.

## Key Elements
- **Syntax** - Format/structure of data
- **Semantics** - Meaning of each section
- **Timing** - Speed and sequencing

## Common Protocols by Layer
| Layer | Protocols |
|-------|-----------|
| Application | HTTP, HTTPS, FTP, DNS, DHCP, SMTP |
| Transport | TCP, UDP |
| Network | IP, ICMP, ARP |
| Data Link | Ethernet, PPP, HDLC |

## Standards Organizations
- [[IETF]] - Internet protocols (RFCs)
- [[IEEE]] - LAN/WLAN standards (802.x)
