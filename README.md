# Huawei HCIA-DATACOM Study Material

## Introduction

The content in this repository is based on the HCIA-Datacom V1.0 Training Material, which is preparation for the Huawei HCIA-Datacom certification exam.

The HCIA-Datacom (Huawei Certified ICT Associate - Datacom) certification validates your knowledge and skills in data communication networks, including network fundamentals, routing & switching, network security, WLAN, WAN technologies, and network automation.

This study material provides a comprehensive review of data communication concepts, Huawei VRP (Versatile Routing Platform), network protocols, and best practices. The goal is to provide students with the core knowledge necessary to be a successful network engineer and pass the HCIA-Datacom certification exam.

## Course Domains

1. **Network Fundamentals** - Data communication basics, network reference models
2. **Huawei VRP Basics** - VRP system fundamentals and configuration
3. **Network Layer & IP Addressing** - IPv4/IPv6 addressing and routing basics
4. **Routing Technologies** - Static routing, OSPF basics
5. **Switching Technologies** - Ethernet switching, VLANs, STP
6. **Network Reliability** - Eth-Trunk, iStack, CSS
7. **Network Security** - ACL, AAA, NAT
8. **Network Services** - DHCP, DNS, FTP, and other services
9. **Wireless & WAN** - WLAN overview, WAN technologies
10. **Network Automation** - SDN, NFV, Network programmability

## Course Objectives

1. Understand data communication network fundamentals and terminology
2. Explain the OSI and TCP/IP reference models
3. Configure and manage Huawei VRP devices
4. Implement IP addressing schemes for enterprise networks
5. Configure static and dynamic routing (OSPF)
6. Implement Ethernet switching and VLAN technologies
7. Configure STP for loop prevention
8. Implement network reliability using link aggregation
9. Configure ACLs for traffic filtering
10. Implement AAA for network security
11. Configure NAT for address translation
12. Understand WLAN and WAN technologies
13. Explain SDN and NFV concepts
14. Implement network automation and programmability
15. Design and deploy campus network architectures
